# Loading documents

## PDF
```python
pdf_loader = PyPDFLoader("RAG.pdf")
pdf_doc = pdf_loader.load()
```

## TXT
```python
txt_loader = TextLoader("RAG.txt")
txt_doc = txt_loader.load()
```

## DOCX
```python
docx_loader = UnstructuredWordDocumentLoader("RAG.docx")
docx_doc = docx_loader.load()
```
