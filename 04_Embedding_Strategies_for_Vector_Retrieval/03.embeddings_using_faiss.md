# Embeddings using FAISS

### **Facebook AI Similarity Search (FAISS)** is a high-performance library developed by Meta AI for efficient similarity search and clustering of dense vectors. In a RAG pipeline, FAISS plays a crucial role in storing and retrieving document embeddings for semantic search.

### The workflow begins by generating embeddings, vector representations of text, using an embedding model such as OpenAI’s text-embedding models, Hugging Face Transformers, or SentenceTransformers. These embeddings are then stored in a FAISS index, which is optimized for fast nearest-neighbour lookups in high-dimensional space.

### When a user issues a query, the query text is embedded into a vector, and FAISS searches its index to find the most semantically similar document vectors.

### By retrieving the most relevant documents based on meaning rather than keyword matches, FAISS enables highly accurate context retrieval for large knowledge bases.

### This recipe demonstrates how to write a program for embedding using FAISS:

1. Load the pre-trained model. The model all-MiniLM-L6-v2 is suitable for generating embeddings.

2. Define a list of documents to be embedded. Each document is a string that will be transformed into a vector representation.

3. Embed the documents. The model.encode method generates embeddings for the list of documents.

4. Create a FAISS index. The index will store the embeddings and allow for efficient similarity search.

5. Add embeddings to the FAISS index. The embeddings are added to the index for later retrieval.

6. Example query to search the FAISS index.

7. Search the index. The search method retrieves the k-nearest neighbors for the query vector.

8. Print the results. The results show the documents that are most similar to the query, along with their distances.
