# Embedding models for offline use

### Embedding models for offline use allow RAG systems to generate vector representations of text without requiring continuous internet connectivity or reliance on cloud-based APIs. This approach is essential for scenarios involving sensitive data, restricted network environments, or cost optimization.

### Offline embedding is typically achieved by downloading and running pre-trained models locally, using frameworks such as Hugging Face Transformers or SentenceTransformers. These models can process text directly on local hardware, ensuring data privacy and compliance with regulations. Once loaded, they can be used to embed documents, queries, or summaries into dense vectors for storage in a local vector database like FAISS or ChromaDB.

### Running embeddings offline not only reduces latency but also gives developers full control over the model’s version, customization, and fine-tuning. This makes offline embedding a powerful choice for building self-contained, secure, and high-performance RAG pipelines

### This recipe demonstrates how to write a program for using embedding models for offline use:

1. Load an offline, pre-trained SentenceTransformer model. This lightweight open-source model (all-MiniLM-L6-v2) runs locally, offering a good balance between speed and accuracy.

2. Load a pre-trained SentenceTransformer model. You can choose a model based on your requirements (speed, size, accuracy).

3. Prepare sample texts to generate embeddings.

4. Generate embeddings for sample texts. The model.encode method processes the texts and returns their embeddings.

5. Print the generated embeddings.
