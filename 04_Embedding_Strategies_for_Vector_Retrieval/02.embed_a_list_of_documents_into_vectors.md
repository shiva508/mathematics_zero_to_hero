# Embed a list of documents into vectors

### This process involves converting a collection of text documents into numerical vector representations (embeddings) that capture their semantic meaning. Each document, regardless of its length or structure, is processed using an embedding model that maps it into a high-dimensional space.

### This recipe demonstrates how to embed a list of documents into vectors:

1. Load the pre-trained model and tokenizer. The model sentence-transformers/all-MiniLM-L6-v2 is suitable for generating embeddings. You can replace it with any other model available in Hugging Face.

2. Define a list of documents to be embedded. Each document is a string that will be transformed into a vector representation.

3. Tokenize the documents. The tokenizer converts the list of documents into a format suitable for the model.

4. Embed the documents.

5. Generate embeddings for the list of documents. The embed_documents function is called with the list of documents to get their embeddings.

6. Print the resulting embeddings. Each embedding is a vector representation of the corresponding document.
