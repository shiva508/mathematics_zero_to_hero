# Noise-resistant embeddings with pre-normalization

### In RAG systems, embeddings act as the bridge between a user query and relevant document chunks. However, real-world data is rarely clean; it will have typo errors, inconsistent casing, formatting artifacts, and sensor or OCR can also distort embedding quality, reducing retrieval accuracy.

### Pre-normalization is a technique that stabilizes embeddings before they enter similarity search or a downstream pipeline.

### Pre-normalization can be applied at various levels in RAG pipelines, as follows:

1. Implementation at the encoder output will ensure all embeddings have a uniform vector norm before being stored in a vector database.

2. On the query side, user queries' embeddings can be normalized before querying the RAG system.

3. It can be implemented at the model level to generate more stable embeddings.
